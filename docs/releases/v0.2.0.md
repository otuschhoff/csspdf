# csspdf v0.2.0

Release date: 2026-09-09.

Status: Unpublished migration baseline. No `v0.2.0` Git tag was published;
[v0.2.1](v0.2.1.md) is the first consumable release in the v0.2 line.

Version 0.2.0 consolidates the public library at the module root. The supported
Go API is now the `github.com/otuschhoff/csspdf` package, whose package name is
`csspdf`.

## Breaking Change

The former `github.com/otuschhoff/csspdf/docflowpdf` package has been removed.
Update consumers from:

```go
import "github.com/otuschhoff/csspdf/docflowpdf"
```

to:

```go
import "github.com/otuschhoff/csspdf"
```

Replace `docflowpdf.` qualifiers with `csspdf.`. Exported rendering behavior is
otherwise unchanged. The old path is not retained as a compatibility facade
because all known consumers are controlled and can migrate with this release.

## Repository Layout

- The public implementation and tests now live at the module root.
- The PDF inspection command moved from root-level command files to
  `cmd/pdfdump` so the root can contain the importable `csspdf` package.
- The patched gofpdf backend moved from `third_party/gofpdf` to the separately
  maintained `github.com/otuschhoff/gofpdf` fork. `go.mod` pins the validated
  revision, so builds need neither embedded backend source nor a local replace.
- Example commands, scripts, coverage gates, fuzz targets, benchmarks, and the
  external-consumer fixture now use the root package.

## Compatibility

- Go 1.26.6 remains the minimum supported toolchain.
- CI continues to cover Go 1.26.6 and Go 1.27.x on Linux, macOS, and Windows
  amd64.
- Existing deprecations remain available through v0.2.x and are scheduled for
  removal in v0.3.0 as documented in
  `docs/architecture/api-compatibility.md`.

See `docs/guides/migration-v0.2.md` for the complete migration guidance.
