# csspdf v0.2.1

Release date: 2026-09-09.

Version 0.2.1 is the first published release in the v0.2 line. The repository
documented a v0.2.0 migration baseline, but no `v0.2.0` Git tag was published.

## Install

```sh
go get github.com/otuschhoff/csspdf@v0.2.1
```

The supported package is:

```go
import "github.com/otuschhoff/csspdf"
```

## Compatibility

Consumers upgrading from v0.1.0 must replace the former import path:

```go
import "github.com/otuschhoff/csspdf/docflowpdf"
```

with the module-root import shown above and replace `docflowpdf.` qualifiers
with `csspdf.`. This is the intentional pre-v1 breaking change documented in
the [v0.2 migration guide](../guides/migration-v0.2.md). The exported root API
has remained stable throughout the subsequent repository reorganization.

## Changes Since v0.1.0

- Moved the supported public Go package to the module root.
- Replaced the embedded backend with the pinned
  `github.com/otuschhoff/gofpdf` module dependency.
- Organized root source and tests by API, asset, payload, render, and template
  responsibility without changing the exported root API.
- Extracted atomic output mechanics into the standard-library-only
  `internal/fileout` package.
- Consolidated repository-local artifacts under the ignored `.build/` tree.
- Consolidated repository commands into one `cmd/csspdf` binary with
  `dom-parse`, `gen-example`, and `pdfdump` commands.
- Reorganized documentation by lifecycle and added executable link checking.

## Support And Security

- Go 1.26.6 is the minimum supported toolchain.
- CI covers Go 1.26.6 and Go 1.27.x on Linux, macOS, and Windows amd64.
- The release quality gate includes formatting, build, vet, static analysis,
  tests, package coverage floors, race detection, and reachable-vulnerability
  scanning.
- No vulnerability exceptions are approved for this release.

Existing v0.2 deprecations remain available and are scheduled for removal in
v0.3.0 as documented in
[`docs/architecture/api-compatibility.md`](../architecture/api-compatibility.md).
